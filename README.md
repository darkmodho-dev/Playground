# Playground

A simple place to learn and practice C++ by writing your own programs.

## Getting started

Create a folder inside `playground/` for each program or topic, then add your `.cpp` files to that folder. For example:

```text
playground/
└── my-first-program/
    └── main.cpp
```

Compile a program from the repository root with a C++17 compiler:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic playground/my-first-program/main.cpp -o my-first-program
./my-first-program
```

On Windows, run `my-first-program.exe` instead.

This repository is a personal collection of C++ practice projects. Add new folders and source files as your work grows.
